🔍 무슨 차이일까?

🔓 취약한 코드 — 쿠키만 확인
# 로그인 쿠키만 있으면 누가 보낸 요청인지 안 따짐
@app.post("/transfer")
def transfer(to, amount):
    user = get_user_from_cookie()   # 쿠키는 자동 전송됨!
    do_transfer(user, to, amount)
🔒 방어된 코드 — CSRF 토큰 확인
# 진짜 은행 페이지에서만 아는 비밀 토큰을 함께 요구
@app.post("/transfer")
def transfer(to, amount, csrf_token):
    if csrf_token != session.csrf_token:
        raise Error("위조된 요청!")   # 공격 페이지는 이 토큰을 모름
    do_transfer(user, to, amount)
핵심 방어법
① CSRF 토큰 — 폼마다 예측 불가능한 비밀값을 넣고 검증
② SameSite 쿠키 설정 (다른 사이트에서 온 요청엔 쿠키 미전송)
③ 중요한 작업은 재인증(비밀번호 재입력, OTP) 요구
