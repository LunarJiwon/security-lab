SQL 인젝션 비밀번호 없이 로그인

로그인할 때 서버는 "이 아이디와 비밀번호가 맞는 사람 있어?"라고 데이터베이스에 물어봐요. 그 질문(SQL 문장)에 내 입력이 그대로 끼워 넣어지면, 질문 자체를 조작해서 비밀번호를 몰라도 통과할 수 있습니다.

모의 사이트 · "학교 포털 로그인"

🔐 로그인

🔓 입력값을 SQL 문장에 그대로 이어붙입니다.
🔒 파라미터 바인딩(?)으로 입력을 데이터가 아닌 값으로만 처리합니다.
💬 서버가 실행하는 SQL
여기에 실제 실행되는 SQL이 표시됩니다
로그인을 시도해보세요.

🎯 공격 미션

비밀번호를 몰라도 로그인하기. 비밀번호 칸에 아래를 넣어보세요.

' OR '1'='1

또는 아이디 칸에 admin' -- 를 넣으면 비밀번호 확인 부분을 통째로 주석 처리해버립니다.

원리 — 원래 질문은 "아이디가 admin이고 비번이 XXX인 사람?"인데, ' OR '1'='1 을 넣으면 "...또는 1=1인 사람?"으로 바뀌어요. 1은 항상 1이니까 모든 사람이 조건에 맞아 로그인이 통과됩니다.

🔍 무슨 차이일까?

🔓 취약한 코드 — 문자열 이어붙이기
# 입력이 SQL 문장 구조를 바꿀 수 있음
sql = "SELECT * FROM users WHERE id='" + id + "' AND pw='" + pw + "'"
🔒 방어된 코드 — 파라미터 바인딩
# 입력은 무조건 "값"으로만 취급됨 (구조 변경 불가)
sql = "SELECT * FROM users WHERE id=? AND pw=?"
cursor.execute(sql, (id, pw))  # ← ?에 안전하게 끼워짐
핵심 방어법
① Prepared Statement / 파라미터 바인딩 사용 (가장 중요!)
② ORM 사용 (장고 ORM, SQLAlchemy 등)
③ 입력값 검증 + 최소 권한 DB 계정
